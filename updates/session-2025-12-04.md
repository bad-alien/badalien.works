# Tech Page: Expandable Project Cards with Modal System - December 4, 2025

Built a complete project showcase system with expandable cards, modal overlays, and intelligent filtering that creates a dynamic portfolio experience for tech projects.

## Component Architecture:
- **ProjectCard Component**: Sleek card layout with alternating text/image positioning
  - Text and image flip sides on alternating cards (left/right pattern)
  - Status badges (Building/Completed/Planned) positioned dynamically to avoid image overlap
  - Tech stack displayed as pill-style chips matching filter button design
  - Smooth hover effects with scale animation and border glow
  - Fully responsive (vertical stack on mobile)

- **ProjectModal Component**: Full-featured overlay for expanded project views
  - Multi-format video support (HTML5, YouTube, Vimeo) with autoplay
  - Image gallery with navigation arrows and dot indicators
  - Full project descriptions with whitespace formatting
  - Primary/secondary CTA buttons for links (Live Demo, GitHub, etc.)
  - ESC key, X button, and click-outside-to-close functionality
  - Smooth fade/scale entrance animations

## Filtering & State Management:
- **Smart Filter Behavior**:
  - Filters remain hidden until scroll OR filter selection
  - Banner only visible when "All" filter is active
  - Specific filter selection triggers header minimization and banner hide
  - Cards filter by category with staggered fade-in animations (150ms delays)
  - Empty state message when no projects match filter

- **Header State Integration**:
  - Header auto-minimizes when non-"All" filter is selected
  - Prevents filter bar overlap with large header
  - Smooth transitions between expanded/minimized states

## Data Structure:
- TypeScript interfaces for projects, media, links, and statuses
- Sample project data with 5 placeholder projects demonstrating:
  - Multiple categories per project
  - Mixed media types (images, YouTube embeds)
  - Variable link configurations
  - All three status types

## Animation Details:
- Card entrance: Staggered fadeInUp (30px translate with opacity)
- Modal entrance: Combined fadeIn + scaleIn animations
- Filter transitions: 500ms duration matching site style
- Hover states: Scale transform with border color transitions
