# Box Animation Hero - January 9, 2026

Implemented animated box intro hero for the Decoded page with GSAP-powered animations.

## Changes:
- Added new BoxAnimationHero component replacing the static intro section
- Box drops in from off-screen with shadow impact animation
- Lid opens using polygon point morphing for proper 2.5D hinge effect on back edge
- Binary digit stream (0s and 1s) flows from box opening in an arch pattern
- Stream curves upward then downward, leading to title entrance from bottom
- Title, subtitle, and description animate in with staggered fade-up effect
- Added prefers-reduced-motion support for accessibility

## Technical Details:
- Installed GSAP with MotionPathPlugin for timeline orchestration and path animation
- Lid animation uses `gsap.to()` with `attr: { points }` to morph SVG polygons
- Bits follow an SVG path using MotionPathPlugin with configurable spread, count, and timing
- All animation parameters exposed in CONFIG object for easy tuning
- Box exits by fading up while content rises from below simultaneously

## Animation Sequence:
1. Box drops from above viewport (1.05s)
2. Lid opens backward on hinge (0.9s, starts at 1.125s)
3. Binary stream emits (60 bits at 95ms intervals, 2s travel time)
4. Box fades out (starts at 5s)
5. Content rises in (starts at 5.7s)
