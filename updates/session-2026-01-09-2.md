# Box Animation Enhancements - January 9, 2026

Enhanced the box animation with dual-lid opening, 5-stream bit fountain, and route group refactoring.

## Changes:
- Refactored decoded page to (decoded) route group for subdomain support
- Updated middleware to handle decoded subdomain routing in development
- Added dual-lid opening animation (back lid opens first, then front lid swings up)
- Implemented 3D ellipse impact lines matching shadow perspective
- Expanded bit stream from 1 to 5 arching columns
- Each stream arches outward from box then falls straight down in parallel columns
- Increased bit count to 1000 with 10ms emit interval for dense effect
- Uniform bit speed at 2.6s for cohesive visual flow

## Technical Details:
- Lid animation uses polygon point morphing for 2.5D effect on both lids
- Impact lines use ellipse ratio (26/140) to match shadow's 3D perspective
- 5 SVG paths define stream trajectories: far-left, left, center, right, far-right
- Bits randomly distributed across paths using Math.random()
- Route group structure enables subdomain-based routing via middleware rewrites

## Animation Sequence:
1. Box drops with exaggerated squish/jiggle on impact (0.55s drop)
2. 3D ellipse impact lines radiate outward (0.25s)
3. Back lid opens backward, front lid swings up (0.9s each, staggered)
4. 5 bit streams emit from box opening (10ms intervals, 2.6s travel)
5. Box exits upward at 5s
6. Bits fade, title rises at 6.5s
