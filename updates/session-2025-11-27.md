## Key Features Implemented This Session

### 1. Void LLM Interface (`/src/app/void/page.tsx`)
- **Privacy-First Architecture**: Zero persistence, zero logging of conversations
- **Session Management**:
  - Unique UUID per browser session
  - Auto-clear on page refresh
  - Manual "END SESSION" button
  - 5-minute inactivity timeout with auto-reset
- **Chat Features**:
  - Send on Enter, Shift+Enter for new line
  - Real-time message streaming ready
  - Error handling for 400, 429, 500, 503 responses
  - Loading states with animated indicators
- **Current State**: Minimal scaffold with brand colors, ready for full Figma design replacement

### 2. Chat API Route (`/src/app/api/chat/route.ts`)
- **Endpoint**: `POST /api/chat`
- **Strict Privacy Policy** ("Void Policy"):
  - NEVER logs message content or replies
  - Only logs metadata: timestamp, session_id, latency, status_code, response_length
  - No database persistence of conversations
- **Features**:
  - Request validation (session_id, messages array, optional params)
  - Rate limiting: 30 requests/min per IP (in-memory tracking)
  - LLM backend adapter for Unraid Docker container
  - Error codes: `VALIDATION_ERROR`, `RATE_LIMIT_EXCEEDED`, `LLM_CONNECTION_ERROR`, `INTERNAL_ERROR`
- **Model**: NeuralDaredevil-8B-abliterated (runs on Unraid server)

### Session Management Flow
```javascript
// Generate UUID on mount
useEffect(() => {
  const newSessionId = crypto.randomUUID();
  setSessionId(newSessionId);
}, []);

// Auto-timeout after 5 min inactivity
const resetInactivityTimer = useCallback(() => {
  if (inactivityTimerRef.current) {
    clearTimeout(inactivityTimerRef.current);
  }
  inactivityTimerRef.current = setTimeout(() => {
    handleClearSession();
  }, 5 * 60 * 1000);
}, [handleClearSession]);
```

### API Request Schema
```typescript
type ChatRequest = {
  session_id: string;
  messages: ChatMessage[];
  max_new_tokens?: number;    // Default: 256
  temperature?: number;        // Default: 0.8
  top_p?: number;             // Default: 0.9
  top_k?: number;             // Default: 50
};

type ChatMessage = {
  role: 'system' | 'user' | 'assistant';
  content: string;
};
```
