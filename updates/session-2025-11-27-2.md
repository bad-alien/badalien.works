# Updates

## The Void Interface - November 27, 2025

Built a complete privacy-focused chat interface at `/void` with cinematic animations and terminal aesthetics.

**Landing Experience:**
- Black hole animation with "ENTER THE VOID" ultra-thin text
- Sequential philosophical whispers that fade in after click
- Smooth 5-second transition sequence to chat

**Chat Interface:**
- Pure black background with orange monospace typography
- Hover-to-reveal copy buttons with 300ms delay (prevents accidental triggers)
- Terminal-style input with dynamic orange glow effects
- Integrated with existing `/api/chat` LLM endpoint
- Science Gothic variable font (2.7MB) loaded locally

**Technical Stack:**
- Framer Motion for all animations
- Tailwind CSS v4 with custom void design tokens
- Full TypeScript with Next.js 15 App Router
- Gemunu Libre + Science Gothic fonts
