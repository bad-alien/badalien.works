# Blackbox Decoded 2025: Horizontal Data Storytelling Experience - December 30, 2025

Implemented "Blackbox Decoded 2025," a high-performance, visually immersive interactive report. The interface features a horizontal one-page scroller with dark-mode aesthetics, data visualizations, and smooth scroll-triggered animations.

## Architectural Features:
- **Horizontal Snap Engine**: Built a `flex overflow-x-auto snap-x snap-mandatory` container that provides a native-feeling horizontal scroll experience with hidden scrollbars.
- **Progress Tracking**: Integrated a fixed-position top `ProgressBar` using Framer Motion's `useScroll` (specifically `scrollXProgress`) to track movement through the report.
- **Section Reveal System**: Custom `HorizontalSection` wrapper using `whileInView` thresholds to trigger entrance animations (Fade Up) as the user scrolls horizontally.

## Interactive Components:
- **Data Visualization (Recharts)**:
  - **Library Expansion Chart**: Area chart showing movie and TV show growth over the year.
  - **Server Load Chart**: Bar chart showing density and usage waves across a 24-hour cycle.
  - Custom tooltips styled with the "Void" aesthetic (blur, borders, and orange accents).
- **Award Showcase**: `AwardSlide` component featuring "Most Watched" posters with "Scale In" spring physics and typography consistent with the main site.

## Visual & Asset Strategy:
- **Placeholder Assets**: Generated custom SVG posters for "Dune: Part Two," "Severance," and "Scavengers Reign" to ensure a complete initial prototype.
- **Navigation**: Integrated a global "Return to Base" navigation system including a floating back button and an end-of-scroll CTA.
- **Global Tokens**: Leveraged existing Tailwind theme tokens (`void-orange`, `void-green`, etc.) for perfect visual cohesion with the existing site.
