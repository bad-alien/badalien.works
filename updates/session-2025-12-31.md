# Decoded Awards Podium UI Improvements - December 31, 2025

Improved the award podium layout for better visual alignment and readability.

## Changes:
- Moved rank indicator (1, 2, 3) from bottom-left to top-left of posters
- Side cards (2nd/3rd place) now show only "Viewed/Played by X users" instead of listing all names
- Center card (1st place) shows user names split into two rows with "+X more" if needed
- Fixed poster alignment so all poster bottoms align horizontally
- Extra text from center card now extends below the baseline instead of pushing poster up
- Supports both "Viewed by" (movies/TV) and "Played by" (artists) formats

## Technical Details:
- Added marginTop offset (120px) to side card posters to align bottoms with center (420px - 300px)
- Regex patterns updated to handle both "viewed" and "played" verbs
- Name list limited to 6 max with "+X more" suffix for overflow
- Container uses items-start alignment so extra text flows downward
