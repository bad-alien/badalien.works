# Blackbox Decoded: Manifest-Driven Architecture & Heatmap Implementation - December 30, 2025 (Part 2)

Transitioned the "Blackbox Decoded" experience to a fully dynamic, manifest-driven architecture. This allows the page to be updated via external data exports from the newsletter repository without code changes.

## Data-Driven Refactoring:
- **Manifest Integration**: The page now consumes `decoded_manifest.json` from the project root. It dynamically renders sections based on type (`intro`, `chart`, `awards`, etc.).
- **Multi-Series Data Support**: Enhanced the `InteractiveChart` component to handle multiple datasets (e.g., Movies, TV Seasons, and Albums) simultaneously.
  - Dynamic generation of gradients and area strokes based on manifest configuration.
  - Improved multi-value custom tooltips with matching color indicators.
  - Added legends for better data clarity.

## New Visualizations:
- **Weekly Usage Heatmap**: Implemented `WeeklyPatternChart.tsx` using a Recharts Scatter Plot approach.
  - Maps 7 days x 24 hours of activity data into a visual "punch card" grid.
  - Bubble sizes (Z-axis) reflect usage intensity.
  - Smooth entrance animations and custom dark-mode tooltips.

## Technical Refinements:
- **Strict Type Safety**: Defined robust TypeScript interfaces for the manifest schema, eliminating `any` types and ensuring safe data flow between the JSON and React components.
- **Build Stabilization**: Fixed several SSR/Hydration issues and cleaned up stale build artifacts that were causing runtime `ENOENT` errors.
