# Vertical Scroll & Owner Message Section - January 6, 2026

Converted the Decoded experience from horizontal to vertical scrolling and added a new owner message section.

## Changes:
- Converted horizontal scroll to vertical scroll with section-by-section snap behavior
- Added `snap-always` to prevent section skipping on macOS trackpads
- Replaced back arrow (→ homepage) with scroll-to-top button (↑) that appears after scrolling
- Added new owner message section after intro with placeholders for Rasheed and Jack
- Added animated glowing "explore" arrow with bounce animation below owner messages

## Technical Details:
- Changed `snap-x` to `snap-y` with `snap-mandatory` for vertical snapping
- Scroll-to-top button uses scroll position tracking via `useEffect` and `scrollTo({ behavior: 'smooth' })`
- Button hidden on landing (opacity-0, pointer-events-none) and fades in after 50% viewport scroll
- Owner messages use side-by-side grid layout with slide-in animations (left/right)
- Explore arrow uses custom SVG with blur glow effect and Framer Motion infinite bounce
