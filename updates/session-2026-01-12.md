# Mobile Responsiveness Fixes - January 12, 2026

Fixed multiple mobile display issues on the decoded page based on user testing feedback.

## Changes:
- Reduced bit animation intensity on mobile to prevent stuttering (350 bits at 28ms vs 1000 at 10ms)
- Converted chart layouts to stack vertically on mobile with legend below
- Improved axis label readability on ridgeline chart (larger fonts, fewer labels on mobile)
- Added swipeable carousel with pagination dots for Top Albums/Artists/TV Shows sections

## Technical Details:
- BoxAnimationHero: Added `getIsMobile()` detection, reduces concurrent DOM elements by ~65%
- InteractiveChart/UserUsageChart: Changed to `flex flex-col md:flex-row` layout
- RidgelineChart: Mobile shows 3-letter day names, hour labels every 4 hours instead of 2
- AwardGroup: Conditional rendering - podium on desktop, snap-scroll carousel on mobile

## Mobile-Specific Behaviors:
1. Bit fountain: 350 bits at 28ms interval (vs 1000 at 10ms on desktop)
2. Charts: Stats panel displays horizontally below chart
3. Ridgeline: Abbreviated day labels (Mon, Tue...), fewer hour markers
4. Award carousels: Full-screen swipe with pagination dots (1, 2, 3)
