# Ridgeline Chart Implementation - January 5, 2026

Replaced the "Pulse of the System" heatmap with a custom D3.js ridgeline/joy plot showing 7 days of hourly server usage data.

## Changes:
- Created new RidgelineChart component using D3.js for smooth curve rendering
- Displays Monday through Sunday with days stacking visually (Monday on top)
- Time axis shifted to 4am-4am window with 1-hour buffer for smooth edge curves
- Applied square root scaling to balance visibility between extreme and smaller values
- 7-color warm-to-cool gradient spectrum anchored to primary orange (#FF6B35)
- Entrance animation with staggered wave reveal (70ms delay per day)
- X-axis shows every other hour (4am, 6am, 8am, etc.)

## Technical Details:
- Uses D3's curveMonotoneX for smooth curves that preserve peaks without overshooting
- SVG clip path hides buffer hours while allowing curves to extend to visible edges
- Square root scaling: `Math.sqrt(value) / Math.sqrt(globalMax)` compresses extremes
- No hover interactions to avoid re-render performance issues
- Color palette: Monday (orange) -> Tuesday (amber) -> Wednesday (coral) -> Thursday (magenta) -> Friday (purple) -> Saturday (indigo) -> Sunday (cyan)
