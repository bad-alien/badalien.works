# BadAlien.Works

Personal portfolio and creative showcase website built with Next.js.

## Development Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/bad-alien/badalien.works.git
   cd badalien.works
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   # Default port 3000
   npm run dev
   
   # Alternative port (if 3000 is blocked)
   PORT=3001 npm run dev
   ```

4. Open your browser:
   - Default: [http://localhost:3000](http://localhost:3000)
   - Alternative: [http://localhost:3001](http://localhost:3001)
